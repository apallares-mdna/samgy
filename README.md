##  Investigación: Importancia del README.md en un Proyecto Web

El archivo `README.md` es la carta de presentación de cualquier repositorio en GitHub. Es el primer punto de contacto que tiene un desarrollador, reclutador o evaluador al revisar un proyecto. 

Su función principal es documentar y comunicar de manera clara, estructurada y comprensible qué hace la aplicación, cómo está construida y de qué forma se puede ejecutar. Para ello se utiliza **Markdown** (.md), un lenguaje de marcado ligero que permite aplicar formato de texto (encabezados, negritas, listas, bloques de código y enlaces) de forma rápida y legible.

### Elementos Esenciales que debe incluir un README.md:
1. **Título y Descripción Corta:** Un resumen directo del propósito y el problema que resuelve el proyecto.
2. **Tecnologías y Herramientas:** Detalle del *stack* tecnológico utilizado (ej. HTML, CSS, JavaScript, Frameworks).
3. **Estructura o Características:** Descripción de las funcionalidades principales y la arquitectura del sistema.
4. **Instrucciones de Instalación y Uso:** Guía paso a paso para clonar, instalar dependencias y ejecutar el proyecto localmente.
5. **Demostración Visual / Capturas:** Imágenes o GIF explicativos del diseño de la interfaz de usuario.
6. **Autores y Créditos:** Mención de los integrantes del equipo de desarrollo y colaboradores.
7. **Bibliografía:** Referencias académicas o documentación consultada para la elaboración del proyecto (bajo normas APA 7).

## Descripción del Problema
En la formación de enfermería del Colegio San Alberto Magno, la recolección y consulta de datos (registros académicos, inventarios de prácticas y seguimiento de estudiantes) requiere rapidez y precisión.

**SAMGY** busca resolver esta problemática ofreciendo un aplicativo web interactivo, organizado y de fácil acceso para estudiantes y docentes.

---

## Objetivos del Proyecto

### Objetivo General
Implementar un sistema web interactivo con React para centralizar la información técnica y administrativa del programa de enfermería.

### Objetivos Específicos
1. Estructurar una interfaz de usuario limpia y accesible para la comunidad educativa.
2. Optimizar los tiempos de consulta de datos en el entorno de prácticas.
3. Mantener un control de versiones profesional del código mediante Git y GitHub.

---

## Tecnologías Utilizadas
* **React:** Librería de JavaScript para construir la interfaz por componentes.
* **Vite:** Herramienta de compilación ultraligera para desarrollo rápido.
* **JavaScript (ES6+):** Lógica de programación del aplicativo.
* **HTML5 & CSS3:** Estructura semántica y diseño visual responsive.
* **Git / GitHub:** Control de versiones e historial de desarrollo colaborativo.
