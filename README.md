##  Descripción del Problema
En la formación de enfermería del Colegio San Alberto Magno, la recolección y consulta de datos (registros académicos, inventarios de prácticas y seguimiento de estudiantes) requiere rapidez y precisión.

**SAMGY** busca resolver esta problemática ofreciendo un aplicativo web interactivo, organizado y de fácil acceso para estudiantes y docentes.

---

## Objetivos del Proyecto

### Objetivo General
Implementar un sistema web interactivo con React para centralizar la información técnica y administrativa del programa de enfermería.

### Objetivos Específicos
1. Estructurar una interfaz de usuario limpia y accesible para la comunidad educativa.
2. Optimizar los tiempos de consulta de datos en el entorno de prácticas.
3. Mantener un control de versiones profesional del código mediante Git y GitHub.

---

## Tecnologías Utilizadas
* **React:** Librería de JavaScript para construir la interfaz por componentes.
* **Vite:** Herramienta de compilación ultraligera.
* **Git / GitHub:** Control de versiones e historial de desarrollo en equipo.
